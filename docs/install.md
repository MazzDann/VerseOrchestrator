# Встановлення й запуск

Ця сторінка — для того, хто готує комп’ютер до показу: що потрібно застосунку, куди
покласти тексти й пісні, як запускати його ярликом чи разом з комп’ютером, як зробити
портативну копію і як вимкнути все повністю. Перший запуск крок за кроком описано у
[Швидкому старті](quickstart.md), а налаштування для розробки — у
[README проєкту](../README.md).

## Вимоги

- Windows, macOS або Linux.
- Chrome або Edge. В інших браузерах застосунок працює, але не відкриває вікна показу на
  вибраному екрані.
- Node.js 22.18 або новіший, краще 24 LTS. Портативній копії він не потрібен: Node.js
  уже в ній.
- Інтернет під час першого запуску: застосунок завантажує свої складники. Портативній
  копії інтернет не потрібен.
- Місце на диску: близько 400 МБ для застосунку (портативна копія — близько 200 МБ) і
  ще для бібліотеки. Бібліотека з 20 перекладів зі словниками займає близько 500 МБ.

## Додайте тексти й пісні

Застосунок читає тексти з модулів MyBible — файлів `*.SQLite3`. Щоб додати тексти:

1. Скопіюйте модулі в папку `modules/` застосунку:
   - переклади Біблії, наприклад `UKRK.SQLite3`;
   - за бажанням — словник Стронга (`*.dictionary.SQLite3`), перехресні посилання
     (`*.crossreferences.SQLite3`) і коментарі (`*.commentaries.SQLite3`) для вкладок
     **Стронг** і **Контекст**.
2. Запустіть застосунок. Під час запуску він збирає з модулів бібліотеку — файл
   `data/library.db`.

Щоб додати модулі пізніше, скопіюйте їх у `modules/`, а тоді у вікні керування відкрийте
**Налаштування вигляду** → **Застосунок** і натисніть **Пересканувати модулі**.

Кладіть у `modules/` лише потрібні модулі. Якщо модулів одного виду більше 60, наприклад
цілий каталог MyBible, застосунок не бере їх у бібліотеку, доки ви не перелічите потрібні
файли у `data/settings.json` → `library` (списки `bibles`, `dictionaries`,
`commentaries`, `crossreferences`).

Пісні зберігаються в бандлах у папці `data/songs/`. Додати їх можна з файлів `.pptx`
імпортом у вікні керування або через папку `songs/` — див.
[Пісні та власний текст](songs-and-text.md#імпортуйте-пісні-з-файлів-pptx).

## Запустіть застосунок

Щоб запустити застосунок, у його папці:

- у Windows двічі клацніть `start.cmd`;
- у macOS двічі клацніть `start.command`;
- у Linux виконайте в терміналі `./start.sh`.

Перший запуск триває кілька хвилин: застосунок встановлює складники, збирає бібліотеку й
інтерфейс. Наступні запуски тривають секунду-дві. Вікно запуску має лишатися відкритим,
доки працює застосунок.

Якщо macOS не відкриває `start.command` з архіву, завантаженого з інтернету, клацніть
файл правою кнопкою й виберіть **Відкрити**.

Якщо у вікні запуску з’являється повідомлення з позначкою ✗ чи !, див.
[Якщо щось не працює](troubleshooting.md).

## Виберіть мову інтерфейсу

Інтерфейс застосунку є українською та англійською. Поки мову не вибрано, застосунок
відкривається мовою браузера: англійською, якщо браузер ставить англійську вище за
українську, інакше — українською.

Щоб змінити мову, у вікні керування відкрийте **Налаштування вигляду** → **Застосунок** і
в полі **Мова інтерфейсу** виберіть **Українська** або **English**. Вибір зберігається
разом з іншими налаштуваннями застосунку.

Тією самою мовою пише й вікно запуску — з наступного запуску застосунку. Телефони глядачів
і пульт доповідача показують мову свого браузера, як і сторінка, що з’являється, поки
застосунок запускається.

## Створіть ярлик

Ярлик запускає застосунок і відкриває вікно керування окремим вікном — без вкладок і
адресного рядка (у Chrome або Edge).

Щоб створити ярлик, у вікні керування відкрийте **Налаштування вигляду** →
**Застосунок** і натисніть **Створити ярлик**. Ярлик з’являється на робочому столі; у
Linux — ще й у меню застосунків.

## Запускайте разом з комп’ютером

Щоб застосунок був готовий, щойно комп’ютер увімкнено, у вікні керування відкрийте
**Налаштування вигляду** → **Застосунок** і ввімкніть **Запуск за адресою**.

Тоді з комп’ютером стартує невеликий процес, який тримає адресу застосунку. Застосунок
запускається, щойно цю адресу відкрити — у браузері комп’ютера чи з телефона. Якщо
застосунком не користуються 15 хвилин, він зупиняється, а адреса чекає далі.

Стандартна адреса — `http://localhost:4747`. Щоб змінити порт, введіть новий у поле
**Порт** під перемикачем, натисніть **Змінити** й підтвердьте. Новий порт діє й для
запуску з `start.cmd`, `start.command` чи `./start.sh`.

## Зробіть портативну копію

Портативна копія — папка із застосунком і Node.js усередині. Її запускають на іншому
комп’ютері з тією самою системою й процесором без встановлення й без інтернету, наприклад
з флешки.

Щоб зробити портативну копію, у папці застосунку виконайте:

```bash
npm run portable
```

Копія з’являється в папці `portable/`, у підпапці з версією, системою й процесором,
наприклад `VerseOrchestrator-VERSION-windows-x64`. У неї потрапляють налаштування вигляду й
послідовність показу. Щоб додати й бібліотеку, виконайте
`npm run portable -- --with-library`.

У копії нагорі лише те, що потрібно користувачеві:

| Що                                          | Навіщо                                                   |
| ------------------------------------------- | -------------------------------------------------------- |
| `start.cmd`, `start.command` або `start.sh` | запуск: файл для системи, для якої зроблено копію        |
| `modules/`                                  | модулі MyBible: застосунок збере з них бібліотеку сам    |
| `data/`                                     | ваші дані: налаштування, бібліотека, пісні               |
| `ЯК ЗАПУСТИТИ.txt`                          | як запустити й вимкнути копію                            |
| `app/`                                      | сам застосунок: код, Node.js, пакети, зібраний інтерфейс |

Щоб оновити копію до нової версії, замініть у ній папку `app/` папкою `app/` з нової
копії. Папки `data/` і `modules/` лишаються як були.

## Вимкніть застосунок повністю

Закрите вікно запуску зупиняє застосунок, але з увімкненим **Запуск за адресою** адреса
чекає далі й стартує разом з комп’ютером. Щоб вимкнути все, у вікні керування відкрийте
**Налаштування вигляду** → **Застосунок**, натисніть **Вимкнути повністю…** і підтвердьте
**Вимкнути**. Щоб стерти й дані застосунку в браузері, перед цим позначте **Також стерти
дані браузера**.

Якщо вікно керування не відкривається, виконайте в терміналі в папці застосунку
`.\start.cmd --off` (у macOS і Linux — `./start.sh --off`). Так вимикається все, крім
даних браузера.

Після цього нічого не працює у фоні й не стартує з комп’ютером, і папку застосунку можна
видалити.
