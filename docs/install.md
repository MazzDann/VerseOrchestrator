# Встановлення й запуск

Українською · [English](en/install.md)

Ця сторінка — для того, хто готує комп’ютер до показу: де взяти застосунок і що йому
потрібно, куди покласти тексти й пісні, як запускати його ярликом чи разом з комп’ютером, у
якому браузері його відкривати, як оновити його, зробити портативну копію і вимкнути все
повністю. Перший запуск крок за кроком описано у [Швидкому старті](quickstart.md), а
налаштування для розробки — у [README проєкту](../README.md).

## Завантажте застосунок

Щоб встановити застосунок:

1. Завантажте архів для своєї системи — посилання ведуть на останній реліз:

   | Система               | Архів                                         |
   | --------------------- | --------------------------------------------- |
   | Windows 10/11 (x64)   | [`VerseOrchestrator-windows-x64.zip`][win]    |
   | macOS (Apple Silicon) | [`VerseOrchestrator-macos-arm64.zip`][mac]    |
   | Linux (x64)           | [`VerseOrchestrator-linux-x64.tar.gz`][linux] |

2. Розпакуйте архів у зручну папку, наприклад у «Документи».

[win]: https://github.com/MazzDann/VerseOrchestrator/releases/latest/download/VerseOrchestrator-windows-x64.zip
[mac]: https://github.com/MazzDann/VerseOrchestrator/releases/latest/download/VerseOrchestrator-macos-arm64.zip
[linux]: https://github.com/MazzDann/VerseOrchestrator/releases/latest/download/VerseOrchestrator-linux-x64.tar.gz

У папці застосунку нагорі лише те, що вам знадобиться:

| Що                                          | Навіщо                                                   |
| ------------------------------------------- | -------------------------------------------------------- |
| `start.cmd`, `start.command` або `start.sh` | запуск                                                   |
| `modules/`                                  | модулі MyBible: застосунок збере з них бібліотеку сам    |
| `data/`                                     | ваші дані: налаштування, бібліотека, пісні               |
| `ЯК ЗАПУСТИТИ.txt`, `HOW TO START.txt`      | як запустити й вимкнути застосунок                       |
| `app/`                                      | сам застосунок: код, Node.js, пакети, зібраний інтерфейс |

Архів уже містить Node.js, тож нічого встановлювати не треба. Контрольні суми архівів
лежать у файлі `SHA256SUMS.txt` на сторінці [останнього релізу](https://github.com/MazzDann/VerseOrchestrator/releases/latest), а
попередні версії — на сторінці [Releases](https://github.com/MazzDann/VerseOrchestrator/releases).

Застосунок можна запускати й з копії репозиторію — так роблять розробники; див.
[README проєкту](../README.md#run-from-the-source).

## Вимоги

- Windows 10 чи 11, macOS на Apple Silicon або Linux (x64). З копії репозиторію
  застосунок працює й на інших процесорах.
- Chrome або Edge. В інших браузерах застосунок працює, але не відкриває вікна показу на
  вибраному екрані.
- Місце на диску: близько 70 МБ на архів і 175 МБ на розпакований застосунок, і ще для
  бібліотеки. Бібліотека з 20 перекладів зі словниками займає близько 500 МБ.
- Для запуску з копії репозиторію — Node.js 22.18 або новіший (краще 24 LTS) та інтернет
  під час першого запуску: застосунок завантажує свої складники. Архіву й портативній
  копії не потрібні ні Node.js, ні інтернет.

## Додайте тексти й пісні

Застосунок читає тексти з модулів MyBible — файлів `*.SQLite3`. Щоб додати тексти:

1. Скопіюйте модулі в папку `modules/` застосунку:
   - переклади Біблії, наприклад `UKRK.SQLite3`;
   - за бажанням — словник Стронга (`*.dictionary.SQLite3`), перехресні посилання
     (`*.crossreferences.SQLite3`) і коментарі (`*.commentaries.SQLite3`) для вкладок
     **Стронг** і **Контекст**.
2. Запустіть застосунок. Під час запуску він збирає з модулів бібліотеку — файл
   `data/library.db`.

Щоб додати модулі пізніше, скопіюйте їх у `modules/`, а тоді у вікні керування відкрийте
**Налаштування вигляду** → **Застосунок** і натисніть **Пересканувати модулі**.

Кладіть у `modules/` лише потрібні модулі. Якщо модулів одного виду більше 60, наприклад
цілий каталог MyBible, застосунок не бере їх у бібліотеку, доки ви не перелічите потрібні
файли у `data/settings.json` → `library` (списки `bibles`, `dictionaries`,
`commentaries`, `crossreferences`).

Пісні зберігаються в бандлах у папці `data/songs/`. Додати їх можна з файлів `.pptx`
імпортом у вікні керування або через папку `songs/` — див.
[Пісні та власний текст](songs-and-text.md#імпортуйте-пісні-з-файлів-pptx).

## Запустіть застосунок

Щоб запустити застосунок, у його папці:

- у Windows двічі клацніть `start.cmd`;
- у macOS двічі клацніть `start.command`;
- у Linux виконайте в терміналі `./start.sh`.

Перший запуск застосунку з архіву збирає бібліотеку з модулів — від кількох секунд до
кількох хвилин. З копії репозиторію перший запуск ще встановлює складники й будує
інтерфейс. Наступні запуски тривають секунду-дві. Вікно запуску має лишатися відкритим,
доки працює застосунок.

Під час першого запуску з архіву система може попередити про файл з інтернету:

- у Windows підтвердьте запуск `start.cmd`;
- у macOS застосунок не підписаний Apple, тож система блокує `start.command`. Відкрийте
  **Системні параметри** → **Приватність і безпека**, натисніть кнопку «Усе одно відкрити»
  (Open Anyway) біля `start.command` і підтвердьте. До macOS 15 досить клацнути файл
  правою кнопкою й вибрати **Відкрити**. Далі файл відкривається звичайним подвійним
  клацанням.

Коли застосунок уже працює й вікно керування відкрите, повторний запуск не відкриває другого
вікна керування, а переводить на це (у Windows; у macOS — коли воно в Chrome, Edge, Brave,
Chromium, Arc чи Safari) або каже, що воно відкрите. У цих браузерах під час першого такого
запуску macOS питає, чи дозволити Терміналу керувати браузером, у якому відкрите вікно
керування, — натисніть «Дозволити» (Allow). Якщо ж вікно керування відкрите у Firefox чи
браузері на його основі, як-от Zen чи LibreWolf, macOS нічого не питає: файл запуску виводить
наперед цей браузер, а потрібне вікно чи вкладку вибрати не може. Якщо дозволу не дали, див.
[Файл запуску не переводить на вікно керування в
macOS](troubleshooting.md#файл-запуску-не-переводить-на-вікно-керування-в-macos).

Якщо у вікні запуску з’являється повідомлення з позначкою ✗ чи !, див.
[Якщо щось не працює](troubleshooting.md).

## Виберіть мову інтерфейсу

Інтерфейс застосунку є українською та англійською. Поки мову не вибрано, застосунок
відкривається мовою браузера: українською чи англійською — тією, яку браузер ставить вище.
Якщо браузер не просить жодної з них, наприклад лише німецьку, застосунок відкривається
англійською.

Щоб змінити мову, у вікні керування відкрийте **Налаштування вигляду** → **Застосунок** і
в полі **Мова інтерфейсу** виберіть **Українська** або **English**. Вибір зберігається
разом з іншими налаштуваннями застосунку.

Тією самою мовою пише й вікно запуску — з наступного запуску застосунку. Телефони глядачів
і пульт доповідача показують мову свого браузера, як і сторінка, що з’являється, поки
застосунок запускається.

## Виберіть браузер

Файл запуску відкриває вікно керування в браузері системи. Щоб відкривати його в іншому
браузері — наприклад, коли браузер системи для роботи, а показ ви ведете в Chrome, — у вікні
керування відкрийте **Налаштування вигляду** → **Застосунок** і в полі **Відкривати вікно
керування в…** виберіть браузер. У списку — **Браузер системи** і браузери, які застосунок
знайшов на цьому комп’ютері. Вибір діє з наступного запуску: так відкривають вікно керування
файл запуску й ярлик.

Щоб вікно керування відкривалося окремим вікном — без вкладок і адресного рядка, —
увімкніть **Окремим вікном**. Так уміють браузери на основі Chromium: Chrome, Edge, Brave,
Arc, Opera, Vivaldi і Chromium. У Firefox, Zen і Safari вікно керування відкривається
звичайним вікном, тож там перемикач вимкнено. Окреме вікно має одну вкладку, тож повторний
запуск надійніше переводить саме на нього.

Щоб перейти в інший браузер одразу, не чекаючи наступного запуску, натисніть кнопку
**Відкрити в … зараз** під перемикачем — наприклад, **Відкрити в Zen зараз**. Вікно керування
відкривається у вибраному браузері (окремим вікном, якщо його увімкнено) і бере керування на
себе: пульти й телефони глядачів слухають уже його. Це вікно пише **Вікно керування перейшло
в …** — закрийте його кнопкою **Закрити це вікно** або лишіть. Вікна показу й сцени, відкриті з
цього браузера, лишаються тут, тож якщо якесь відкрите, застосунок спершу питає: натисніть
**Перейти в …** і відкрийте показ знову в новому вікні керування. Кнопки немає, коли вибрано
**Браузер системи**, і у вибраному браузері, щойно застосунок сам відкрив у ньому вікно
керування — файлом запуску, ярликом чи цією кнопкою. У вікні, яке ви відкрили за адресою самі,
кнопка може лишитися й у вибраному браузері: браузери на одному рушії часто називають себе
однаково (як-от Firefox, Zen і LibreWolf), а друге вікно керування там нічому не шкодить.

Якщо вибраного браузера на комп’ютері більше немає, файл запуску відкриває вікно керування,
як із **Браузер системи**, — у браузері системи, а з ярлика окремим вікном у Chrome чи Edge, —
і пише про це у вікні запуску. Вибір зберігається у `data/settings.json` → `launch`.

Під полем видно версію застосунку — та сама стоїть угорі **Налаштування вигляду**. Копія з
репозиторію пише там `dev` і гілку, наприклад `dev 1.4.4.try3 (feat/x · 36f9ddd)`.

## Створіть ярлик

Ярлик запускає застосунок і відкриває вікно керування окремим вікном — без вкладок і
адресного рядка: у браузері, вибраному в **Відкривати вікно керування в…**, якщо він на
основі Chromium, а з **Браузер системи** — у Chrome чи Edge. Firefox, Zen і Safari відкривають
його звичайним вікном.

Щоб створити ярлик, у вікні керування відкрийте **Налаштування вигляду** →
**Застосунок** і натисніть **Створити ярлик**. Ярлик з’являється на робочому столі; у
Linux — ще й у меню застосунків.

## Запускайте разом з комп’ютером

Щоб застосунок був готовий, щойно комп’ютер увімкнено, у вікні керування відкрийте
**Налаштування вигляду** → **Застосунок** і ввімкніть **Запуск за адресою**.

Тоді з комп’ютером стартує невеликий процес, який тримає адресу застосунку. Застосунок
запускається, щойно цю адресу відкрити — у браузері комп’ютера чи з телефона. Якщо
застосунком не користуються 15 хвилин, він зупиняється, а адреса чекає далі.

Стандартна адреса — `http://localhost:4747`. Щоб змінити порт, введіть новий у поле
**Порт** під перемикачем, натисніть **Змінити** й підтвердьте. Новий порт діє й для
запуску з `start.cmd`, `start.command` чи `./start.sh`.

## Оновіть застосунок

Застосунок сам дізнається про нові версії: раз на 12 годин він питає GitHub, чи вийшла
новіша. Коли вона є, на кнопці **Налаштування вигляду** з’являється крапка, а в
**Налаштування вигляду** → **Застосунок** → **Оновлення** — номер нової версії й посилання
**Що нового**. Кнопка **Перевірити зараз** питає одразу. Щоб застосунок не звертався до
GitHub, вимкніть **Перевіряти оновлення**. Завантажує й установлює нову версію застосунок
лише тоді, коли ви натиснете кнопку.

Версії 0.x — попередні: поки у вас 0.x, застосунок пропонує й попередні версії, а з 1.0.0 —
лише звичайні релізи.

### Оновіть застосунок з архіву

Щоб оновити застосунок, установлений з архіву:

1. У **Налаштування вигляду** → **Застосунок** → **Оновлення** натисніть **Завантажити
   оновлення**. Застосунок завантажує архів нової версії, звіряє його контрольну суму й
   розпаковує поруч із папкою `app/`. Показ тим часом триває.
2. Якщо відкриті вікна виводу, закрийте їх: під час показу застосунок не перезапускається.
3. Натисніть **Перезапустити й оновити**. За кілька секунд застосунок запускається вже в
   новій версії: вікно керування перезавантажується саме, телефони під’єднуються знову.

Нова версія працює у фоні, як із **Запуск за адресою**: вікно запуску закривається разом зі
старою версією. Щоб зупинити застосунок, натисніть **Вимкнути повністю** в **Налаштування
вигляду** → **Застосунок**.

Якщо нова версія не відповідає за півтори хвилини, застосунок повертає попередню й пише про
це в **Оновлення**, а подробиці — у `data/updates/swap.log`. Попередня версія лишається в
папці `app.previous/` до наступного оновлення, а версія, що не запустилася, — в
`app.failed/`.

Папки `data/` і `modules/` оновлення не зачіпає: налаштування, бібліотека, пісні й модулі
переходять у нову версію.

### Поверніть попередню версію

Якщо з новою версією щось не так, поверніть ту, що була до оновлення:

1. Закрийте вікна виводу: під час показу застосунок не перезапускається. Якщо оновлення саме
   розпаковується, дочекайтеся, доки воно буде готове. Завантаження, яке ще триває, зупиниться.
2. У **Налаштування вигляду** → **Застосунок** → **Оновлення** натисніть **Повернути версію
   …** з номером попередньої версії, а тоді **Повернути** в підтвердженні.

За кілька секунд застосунок працює в попередній версії, а **Оновлення** пише «Повернуто
версію …». Версія, з якої ви повернулися, лишається поруч, тож до неї можна перейти тією
самою кнопкою. Якщо попередня версія не запуститься, застосунок лишить ту, що була.

Версії до 1.4.0 ще не вміють повертати версії. Якщо ви повернулися на таку версію, кнопки
**Повернути версію …** у ній немає, а **Оновлення** пише «Оновлено з … до …». Щоб знову
перейти на новішу версію, оновіть застосунок, як описано вище: для цього потрібен інтернет.
Якщо ви поверталися з версії 1.4.1 чи новішої і вона досі остання, завантажувати її знову не
доведеться: **Оновлення** одразу запропонує **Перезапустити й оновити**. Після повернення з
1.4.0 архів доведеться завантажити знову.

### Встановіть іншу версію

Застосунок, установлений з архіву, може перейти на будь-яку звичайну версію від 1.0.0 —
новішу чи старішу:

1. У **Налаштування вигляду** → **Застосунок** → **Оновлення** виберіть версію в списку поруч
   із кнопкою завантаження. Якщо списку ще немає, натисніть **Перевірити зараз**.
2. Натисніть **Завантажити версію …**. Застосунок завантажує її архів, звіряє контрольну суму
   й розпаковує поруч, як і під час оновлення.
3. Закрийте вікна виводу й натисніть **Перезапустити з версією …** (для новішої версії —
   **Перезапустити й оновити**).

Щоб передумати до перезапуску, виберіть у списку іншу версію й завантажте її: вона замінить
завантажену.

Старіша версія не знає того, що з’явилося пізніше: частину налаштувань вона може скинути до
типових. Тому перед переходом [збережіть резервну копію](#збережіть-резервну-копію): після
повернення з неї можна відновити все, що в ній є.

Повернутися на версію, з якої ви перейшли, можна кнопкою **Повернути версію …**. У версіях до
1.4.0 такої кнопки ще немає: з них можна лише оновитися до найновішої версії, і для цього
потрібен інтернет. Якщо найновіша — саме та, з якої ви перейшли, завантажувати її знову не
доведеться.

Поки працює версія, яку ви вибрали замість найновішої, застосунок не нагадує про оновлення:
кнопка **Налаштування вигляду** без позначки, а в розділі **Оновлення** написано «Ви вибрали
версію …». Так само після кнопки **Повернути версію …**, що веде на старішу версію. Про реліз,
новіший за тодішній найновіший, застосунок нагадає знову. Щоб повернутися на найновішу стабільну версію, натисніть **Поточний
реліз …**, а тоді **Перезапустити й оновити**. Так поводяться версії від 1.6.3; старіші
нагадують про найновішу завжди.

### Оновіть вручну

Версії до 1.0.0 не вміють оновлюватися самі. Щоб оновити таку версію або якщо оновлення
кнопкою не вдалося:

1. Зупиніть застосунок: натисніть **Вимкнути повністю** або закрийте вікно запуску.
2. Завантажте архів нової версії зі сторінки [Releases](https://github.com/MazzDann/VerseOrchestrator/releases) і розпакуйте його в
   окрему папку.
3. Замініть папку `app/` свого застосунку папкою `app/` з нової версії.

### Оновіть копію репозиторію

Копія репозиторію, запущена файлом запуску, сама перевіряє, чи є нові зміни, і отримує їх на
ваш запит:

1. У **Налаштування вигляду** → **Застосунок** → **Оновлення** натисніть **Перевірити зараз**.
   Застосунок питає віддалений репозиторій і каже, скільки нових змін на гілці, за якою стежить
   ваша (наприклад, `origin/main`). З увімкненим **Перевіряти оновлення** він питає й сам,
   двічі на добу.
2. Натисніть **Отримати оновлення**. Застосунок отримує зміни (`git pull`) лише тоді, коли це
   можна зробити без вашого рішення: у файлах немає незбережених змін і гілка не розійшлася з
   віддаленою. Інакше він каже, чому, — тоді отримайте зміни вручну.

Щойно код змінився — після **Отримати оновлення**, `git pull` вручну чи переходу на іншу
гілку, — застосунок помічає це за хвилину: на значку **Налаштування вигляду** з’являється
крапка, а в **Оновлення** — кнопка **Перезапустити**. Натисніть її: застосунок сам встановить нові складники, перебудує
інтерфейс і запуститься знову у фоні, а сторінка оновиться сама. Вікно запуску при цьому
закриється. Поки відкриті вікна виводу, кнопка недоступна.

Після перезапуску застосунок працює у фоні, як із **Запуск за адресою**. Щоб зупинити його,
натисніть **Вимкнути повністю** в **Налаштування вигляду** → **Застосунок**. Так само можна
обійтися без кнопки: зупиніть застосунок і запустіть його файлом запуску ще раз.

## Збережіть резервну копію

Резервна копія — один файл `.zip` з того, що ви налаштували й зібрали в застосунку: вигляд
слайдів, пресети, гарячі клавіші, закладки й історію, послідовність показу й збережені
програми, бандли пісень і зображення. Модулі й бібліотеки в ній немає, бо їх великі файли
лежать у папці `modules/`. Немає в ній і пультів доповідача та налаштувань запуску цього
комп’ютера: порту, браузера, вибору модулів.

Щоб зберегти копію, у вікні керування відкрийте **Налаштування вигляду** → **Застосунок** і
в розділі **Резервна копія** натисніть **Зберегти копію**. Браузер завантажує файл на зразок
`VerseOrchestrator-backup-2026-10-01-1405.zip`. Тримайте його поза папкою застосунку,
наприклад на флешці. Safari на Mac може сам розпакувати завантажений файл у папку: тоді
стисніть цю папку у Finder (**Стиснути**) — застосунок прийме й такий файл.

Щоб відновити копію на цьому чи іншому комп’ютері:

1. У тому самому розділі натисніть **Відновити з копії…** і виберіть файл копії.
2. Перевірте, що в ній: застосунок показує дату копії, кількість програм і пунктів
   послідовності, бандли пісень і кількість зображень. Поки ви не натиснули **Відновити**,
   нічого не змінюється.
3. Натисніть **Відновити**. Вікно керування перезавантажується з відновленим станом.

Інші відкриті вікна керування беруть відновлені налаштування одразу. Поки копія
зберігається чи відновлюється, зміни пісень і зображень чекають, доки вона закінчиться.

Застосунок переносить стан, який замінила копія, в окрему папку в `data/backups/`: файли
пісень і зображень лежать там такими, якими були. Протягом доби після відновлення його можна
повернути: натисніть **Повернути як було** в розділі **Резервна копія** і підтвердьте
кнопкою **Повернути**. Те, що змінено після відновлення, теж зберігається в `data/backups/`.

Копія буває до 1 ГБ. Якщо зображень більше, застосунок про це скаже й копії не зробить.

## Зробіть портативну копію

Портативна копія — папка із застосунком і Node.js усередині. Її запускають на іншому
комп’ютері з тією самою системою й процесором без встановлення й без інтернету, наприклад
з флешки.

Щоб зробити портативну копію, у папці застосунку виконайте:

```bash
npm run portable
```

Потрібен Node.js з [nodejs.org](https://nodejs.org) або встановлений через fnm чи nvm: у
копію потрапляє саме він. Node.js з Homebrew залежить від бібліотек Homebrew, тож його копія
не запуститься, і `npm run portable` відмовиться її робити.

Копія з’являється в папці `portable/`, у підпапці з версією, системою й процесором,
наприклад `VerseOrchestrator-VERSION-windows-x64`. У неї потрапляють налаштування вигляду й
послідовність показу. Щоб додати й бібліотеку, виконайте
`npm run portable -- --with-library`.

У копії нагорі лише те, що потрібно користувачеві:

| Що                                          | Навіщо                                                   |
| ------------------------------------------- | -------------------------------------------------------- |
| `start.cmd`, `start.command` або `start.sh` | запуск: файл для системи, для якої зроблено копію        |
| `modules/`                                  | модулі MyBible: застосунок збере з них бібліотеку сам    |
| `data/`                                     | ваші дані: налаштування, бібліотека, пісні               |
| `ЯК ЗАПУСТИТИ.txt`                          | як запустити й вимкнути копію                            |
| `app/`                                      | сам застосунок: код, Node.js, пакети, зібраний інтерфейс |

Щоб оновити копію до нової версії, замініть у ній папку `app/` папкою `app/` з нової
копії. Папки `data/` і `modules/` лишаються як були.

## Вимкніть застосунок повністю

Закрите вікно запуску зупиняє застосунок, але з увімкненим **Запуск за адресою** адреса
чекає далі й стартує разом з комп’ютером. Щоб вимкнути все, у вікні керування відкрийте
**Налаштування вигляду** → **Застосунок**, натисніть **Вимкнути повністю…** і підтвердьте
**Вимкнути**. Щоб стерти й дані застосунку в браузері, перед цим позначте **Також стерти
дані браузера**.

Якщо вікно керування не відкривається, виконайте в терміналі в папці застосунку
`.\start.cmd --off` (у macOS і Linux — `./start.sh --off`). Так вимикається все, крім
даних браузера.

Після цього нічого не працює у фоні й не стартує з комп’ютером, і папку застосунку можна
видалити.
