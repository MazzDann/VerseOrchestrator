# Довідка

Українською · [English](en/reference.md)

Ця сторінка — довідка для оператора й того, хто налаштовує застосунок: гарячі клавіші,
параметри запуску, файли застосунку, адреси й порти. Як виконувати завдання — у розділах
з [документації](README.md).

## Гарячі клавіші

Клавіші вікна керування стандартно такі. Змінити їх можна в **Налаштування вигляду** →
**Гарячі клавіші**; підказки на кнопках показують поточні клавіші.

| Дія                             | Windows і Linux | Додатково в macOS   |
| ------------------------------- | --------------- | ------------------- |
| **Далі** — наступний вірш       | →, ↓, PageDown  |                     |
| **Назад** — попередній вірш     | ←, ↑, PageUp    |                     |
| **Прев’ю: далі** — лише прев’ю  | Ctrl+→, Ctrl+↓  | ⌥→, ⌥↓ замість Ctrl |
| **Прев’ю: назад** — лише прев’ю | Ctrl+←, Ctrl+↑  | ⌥←, ⌥↑ замість Ctrl |
| **На екран**                    | F5, F2          | ⌘↩                  |
| **Сховати текст**               | B               |                     |
| **Чорний екран**                | . (крапка)      |                     |
| **Очистити** — прибрати слайд   | Esc             |                     |
| **Повернути на екран**          | Ctrl+Z          | ⌘Z                  |
| Пошук у головному перекладі     | F3, Ctrl+F      | ⌘F                  |
| Пошук в усіх перекладах         | F4              | ⇧⌘F                 |
| Палітра команд                  | Ctrl+K, Ctrl+P  | ⌘K                  |

У macOS F-клавіші працюють разом з Fn, тому там стандартно є й клавіші з ⌘.

Інші клавіші вікна керування:

- Enter на вірші в списку — показати цей вірш на екрані.
- Пробіл на вірші — вибрати його; Ctrl+пробіл, Shift+пробіл, Ctrl+Enter чи Shift+Enter —
  додати вірш до вибраних або прибрати з них.
- Ctrl+Enter (у macOS — ⌘↩) у панелі **Текст на екран** — показати власний текст.
- Alt+↑ і Alt+↓ прокручують список, у якому ви зараз (інакше — список віршів), не змінюючи
  вибору. У macOS ⌥ зі стрілками — це **Прев’ю: далі** і **Прев’ю: назад**.
- Поки відкрита пісня, стрілки, PageUp і PageDown гортають її слайди, а **Прев’ю: далі** і
  **Прев’ю: назад** нічого не роблять.

У вікні показу:

| Клавіша                | Дія                   |
| ---------------------- | --------------------- |
| F або клацання у вікні | на весь екран і назад |
| →, ↓, PageDown         | **Далі**              |
| ←, ↑, PageUp           | **Назад**             |
| . (крапка)             | **Чорний екран**      |

У вікні **Сцена** F розгортає вікно на весь екран. Клавіші Bluetooth-клікера на телефоні
доповідача описано в розділі [Пульт доповідача](remote.md#що-бачить-доповідач).

## Параметри запуску

Параметри передають файлу запуску в терміналі, у папці застосунку, наприклад
`.\start.cmd --check` у Windows чи `./start.sh --no-browser` у macOS і Linux.

| Параметр       | Що робить                                                                                 |
| -------------- | ----------------------------------------------------------------------------------------- |
| `--no-browser` | Не відкриває браузер — для комп’ютера без екрана або щоб відкрити адресу самому.          |
| `--port N`     | Запускає на порту `N` замість порту з налаштувань (стандартно 4747) — лише цього разу.    |
| `--check`      | Перевіряє Node.js, складники, бібліотеку, інтерфейс і порт і нічого не змінює.            |
| `--off`        | Вимикає застосунок повністю, як **Вимкнути повністю…**, крім даних браузера.              |
| `--app`        | Відкриває вікно керування окремим вікном без вкладок і адресного рядка (Chrome або Edge). |
| `--shortcut`   | Створює ярлик на робочому столі, який запускає застосунок з `--app`, і завершується.      |
| `--new-window` | Відкриває ще одне вікно керування, навіть коли одне вже відкрите.                         |

## Файли й папки

Усе, що застосунок пам’ятає, лежить у його папці:

| Шлях                 | Що там                                                                                              |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| `modules/`           | модулі MyBible (`*.SQLite3`), з яких збирається бібліотека                                          |
| `songs/`             | пісні в презентаціях (`*.pptx`), які застосунок переносить у бандл                                  |
| `data/songs/`        | бандли пісень (`*.vosongs`)                                                                         |
| `data/library.db`    | бібліотека: переклади, словники, коментарі, пісні й пошуковий індекс                                |
| `data/ui-state.json` | налаштування вигляду, пресети, гарячі клавіші, послідовність показу й програми                      |
| `data/settings.json` | параметри сервера: порт і тривалість очікування (`standby`), пульти (`remotes`), модулі (`library`) |
| `data/secrets.json`  | хеші кодів пультів                                                                                  |
| `data/standby.log`   | журнал очікувача адреси                                                                             |
| `portable/`          | портативні копії, зроблені командою `npm run portable`                                              |

Браузер зберігає лише копії налаштувань і кеш бібліотеки. Їх стирає **Вимкнути
повністю…** з позначкою **Також стерти дані браузера**.

Щоб застосунок брав дані з інших місць, задайте змінні середовища перед запуском:

| Змінна          | Що задає                                    | Стандартно                                                  |
| --------------- | ------------------------------------------- | ----------------------------------------------------------- |
| `VO_DATA_DIR`   | папку з даними                              | `data/`; у портативній копії — `data/` поруч з `app/`       |
| `LIBRARY_DB`    | файл бібліотеки                             | `data/library.db`                                           |
| `MODULES_DIR`   | папку з модулями MyBible                    | `modules/`; у портативній копії — `modules/` поруч з `app/` |
| `SONGS_DIR`     | папку з піснями `.pptx`                     | `songs/`                                                    |
| `VO_UPDATE_URL` | адресу, де застосунок питає про нові версії | список релізів проєкту на GitHub                            |

Вікно запуску пише мовою, вибраною у вікні керування. Щоб задати йому іншу, запустіть
застосунок зі змінною `VO_LANG=en` або `VO_LANG=uk`.

## Адреси й порти

Застосунок відповідає за такими адресами (порт 4747 стандартний; його змінює поле
**Порт** у **Налаштування вигляду** → **Застосунок**):

| Адреса                            | Що відкриває                        |
| --------------------------------- | ----------------------------------- |
| `http://localhost:4747/`          | вікно керування                     |
| `http://localhost:4747/presenter` | вікно показу                        |
| `http://localhost:4747/stage`     | вікно **Сцена**                     |
| `http://localhost:4747/settings`  | налаштування вигляду окремим вікном |
| `http://COMPUTER_IP:4747/follow`  | сторінку для телефонів глядачів     |
| `http://COMPUTER_IP:4747/remote`  | пульт доповідача (з кодом із QR)    |

Замініть `COMPUTER_IP` на IP-адресу комп’ютера в мережі Wi-Fi — її друкує вікно запуску.

Вікно керування, налаштування й пульти приймають команди лише з цього комп’ютера або з
телефона з кодом пульта. Телефони в мережі дістаються до застосунку тільки через адресу
з портом 4747; сам сервер застосунку слухає лише цей комп’ютер.
