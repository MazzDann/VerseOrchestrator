# Документація VerseOrchestrator

VerseOrchestrator показує Біблію та інші тексти на кількох екранах. Ви шукаєте й
вибираєте вірші у вікні керування, а вони з’являються у вікні показу на другому моніторі
чи проєкторі. Глядачі можуть стежити за текстом зі своїх телефонів, а доповідач — гортати
показ зі свого.

Ця документація — для операторів, які готують і ведуть показ, і для тих, хто встановлює
застосунок на комп’ютер.

## Почніть тут

- [Швидкий старт](quickstart.md): запуск застосунку й перший вірш на другому екрані.

## Для оператора

- [Як знайти текст](find-text.md): переклади, місце в Біблії, пошук, історія, Стронг.
- [Як показати текст](show-text.md): прев’ю й екран, гортання, вікна виводу, сцена.

## Про проєкт

Короткий опис, ліцензія й команди для розробки — у [README проєкту](../README.md).
