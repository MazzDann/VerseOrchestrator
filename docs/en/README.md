# VerseOrchestrator documentation

[Українською](../README.md) · English

VerseOrchestrator shows the Bible and other texts on several screens. You find and select
verses in the control window, and they appear in the presentation window on a second
monitor or a projector. Viewers can follow the text on their phones, and a speaker can
step through the show from theirs.

This documentation is for operators who prepare and run the show, and for whoever installs
the app on the computer. In the control window, the **Help** button (the question mark at
the top right) opens it in the interface language. It names the buttons as the English
interface does; to switch the interface to English, see
[Choose the interface language](install.md#choose-the-interface-language).
